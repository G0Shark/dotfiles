### Обход ограничений (For russians)
Для обхода ограничений я использую AWGProxy в связке с Clash-Meta (Mihomo). Оба можно скачать через Go, либо clash-meta через AUR. В [Другом репо](https://github.com/G0Shark/ObhodBlokirovok) я выкладывал небольшой софт для Windows, оттуда можете скачать hosts (чтобы открыть ChatGPT и др.) и конфиги для clash и awgproxy. Немного поразбирайтесь в обоих прогах и по желанию создайте сервис для автозапуска. В моём rice на waybar-е есть иконка которая управляет awgproxy\clash-meta.service.

# All configs is need to be corrected for your system.
Like in hyprland.conf i have direct paths for my user, you need to **change it for yours**. I dont love to full-copy any rises, and think you also need to build your OS by yourself (otherwise you maybe dont understand all linux experience). I recomended to use this repo for refernce.
